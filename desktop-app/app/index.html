🔄 CSV 数据导入 / 导出 一次可导入多天，导入后自动算分
表头 14 列（括号里就是单位），列顺序不限、缺列可省：日期(必填，YYYY-MM-DD)、入睡时间 / 起床时间(24 小时制)、睡眠时长(小时，填夜间、不含午休)、运动时长(分钟)、饮水量(ml)、早餐 / 午餐 / 晚餐(吃了填「是」，没吃填「否」)、主要食物(食堂 / 外卖 / 自己做 / 快餐 / 均衡)、久坐时长(小时)、精神状态与身体自评(1-5)、备注、追问(可选，形如 sleep_short=work;water=forget，点按钮答会自动写入，一般不用手填)。三餐三列按「吃了填是、没吃填否」填，三列都填才算完整；如果这天压根没记三餐，三列全留空即可——只有三列全空才会被当作「没记三餐」、不参与评分。
JSON 是完整快照（含追问答案），换手机或清数据前导一份；CSV 适合拿去 Excel 看。
